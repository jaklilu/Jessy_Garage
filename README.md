# Jessy Garage Doors & Screens

Bilingual (EN/ES) marketing site for Jessy Garage Doors — Bell / Los Angeles County.

## Stack

- Vite + React + TypeScript
- React Router (locale-prefixed routes: `/en`, `/es`)
- Netlify hosting + Netlify Forms

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- SPA redirects configured in `netlify.toml`
- Contact form uses Netlify Forms (`form-name=contact`)
